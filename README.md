# IM Motors Azerbaijan — сайт v2

Тёмный «кинематографичный» дизайн, 3 языка (AZ / RU / EN), фото с официального CDN IM.
`index.html` — собранное превью (пересобрать: `bash build.sh`). В Tilda вставляются файлы из `blocks/`.

## Cloudflare и редактор SpectrTech (основной хостинг с ноября 2026)

Сайт immotors.az — Cloudflare Worker `spectrtech-immotors-az`: страницы и фото отдаются как статика, Worker нужен только редактору.

- **Сборка:** `bash build.sh && perl build-cf.pl` → `deploy/` (страницы, фото в `public/img/`, файлы редактора, sitemap, robots,
  `_redirects`, `_headers`, `worker.js`, `wrangler.toml`). Фото берутся с Tilda CDN по `tilda-import/cdn-map.tsv` и кешируются в `deploy/public/img/`.
- **Публикация:** push в `main` → Cloudflare Workers Builds (корневая папка `deploy`) сам выполняет `npx wrangler deploy`.
- **Домен (с 10.11.2026):** зона immotors.az в Cloudflare, NS `coen.ns.cloudflare.com` и `kristina.ns.cloudflare.com`.
  - Сайт подключён маршрутом Worker `immotors.az/*` → `spectrtech-immotors-az`. Маршрут задан в Cloudflare, а не в `wrangler.toml`. Не добавляйте в `wrangler.toml` ключи `routes`/`route`: следующая выкладка заменит ими маршрут.
  - `www` → `immotors.az` — правило Rules → Redirect Rules (301); http → https — настройка Always Use HTTPS.
  - Запись A `immotors.az` → 176.57.64.223 (прежний адрес Tilda, через прокси) — заглушка: запросы до Tilda не доходят, их обрабатывает Worker.
  - MX `emx.mail.ru` (приоритет 10) — почта @immotors.az на Mail.ru, не трогать.
- **Редактор владельца:** immotors.az/mainedit (пароль).
  - Тексты AZ/RU/EN — клик по тексту; фото — клик по фото; телефоны и ссылки — вкладка контактов.
  - Цифры — клик по цифре или вкладка «Lists» → «Rəqəmlər / Цифры». Сюда входят шапка модели, цифры обзора, таблица характеристик и цифры на главной. Значение одно на все языки; число и единицу пишут через пробел, например «787 hp».
  - Шапку, CTA и подвал правят на главной — правка расходится по всем страницам.
  - Правки хранятся в KV (`content`, история — 50 версий), не в git.
- **Как тексты связаны с редактором:**
  - У каждой тройки `<span data-l>` есть ключ `data-i18n-html="t<8 знаков md5 трёх текстов>"` (его ставит build-cf.pl). Правки применяет `cms/imx-cms.js`.
  - Если поменять текст в исходнике, правка владельца для этого текста перестанет применяться.
- **Как цифры связаны с редактором:**
  - build-cf.pl ставит каждой цифре `data-st="SPECS_<хеш состава>.<n>" data-sk="<id>"`.
  - id состоит из раздела, модели, ключа подписи и колонки таблицы. В `st-config.js` у страницы появляется список `SPECS_<хеш>` с подписями.
  - `cms/imx-cms.js` применяет правки по id. Если состав цифр меняется (например, добавили строку в таблицу), меняется хеш. Прежние правки тогда переносятся в новый список по id.
- **Кеш:** адреса скриптов и стилей `/assets/…` в страницах и в mainedit.html получают `?v=<md5 файла>`. `/assets/*` кешируются на час, а так после выкладки браузер сразу берёт новый файл.
- **Статистика:** `cms/imx-stat.js` — Google Analytics 4 (`G-HLB14Z15HG`) и Яндекс Метрика (`100653801`), те же счётчики, что стояли на Tilda. Считают только immotors.az: на workers.dev, локально и в редакторе не работают.
- **Комплект редактора:** `cms/kit` — копия `spectrtech/spectrtech-demos/kit/st-editor` (коммит в `cms/kit/VERSION`); страница редактора — `cms/mainedit.html`.
- **Локально:** конфигурация `immotors-cf` в `.claude/launch.json` (`npx wrangler dev`, порт 8788); пароли — в `deploy/.dev.vars` (не в git).
- **Не трогают редактор:** блок «В наличии» (turbo.az), структура страниц, юридические тексты.
  Цифры в `pages/data/models.json` и в блоках — значения по умолчанию; правки из редактора ложатся поверх них.

## Как вставить в Tilda

1. **Настройки сайта → Ещё → «HTML-код для вставки внутрь head»** → содержимое `blocks/00-globals.html` (один раз на весь сайт).
2. **Настройки сайта → Цвета и шрифты**: фон страницы `#0a0a0b`.
3. На странице создайте по блоку **T123 (HTML-код)** на каждый файл, по порядку:

| # | Файл | Что это |
|---|------|---------|
| 1 | `01-header.html` | Шапка, переключатель языков, мобильное меню |
| 2 | `02-hero.html` | Полноэкранный слайдер LS9 / LS8 / LS6 |
| 3 | `03-intro.html` | Манифест бренда + цифры |
| 4 | `04-models.html` | Витрина 6 моделей |
| 5 | `05-tech.html` | AIOS / Lingxi Chassis / IM AD |
| 6 | `06-servis.html` | Сервис ONVOLT: видео YouTube (ID в data-yt), запись + 6 услуг |
| 7 | `07-4ws.html` | Задние колёса: видео + схема режимов (Город / Трасса / Краб) |
| 8 | `08-stock.html` | Машины в салоне из turbo.az (см. ниже) |
| 9 | `09-cta.html` | Финальный призыв к тест-драйву |
| 10 | `10-footer.html` | Подвал с контактами |

4. У каждого блока T123: **Настройки → Отступы сверху и снизу = 0**.
5. Опубликуйте. Язык меняется кнопками AZ/RU/EN или ссылкой `?lang=ru` / `?lang=en`.

## Машины в салоне (turbo.az)

Блок `08-stock.html` показывает машины из салона https://turbo.az/avtosalonlar/onvolt-im-motors:
фото, модель, комплектация, год, пробег, двигатель/батарея. Цен нет, «Sifarişlə» пропускаются.
Клик по карточке открывает объявление на turbo.az.

turbo.az блокирует автоматические запросы с серверов (Cloudflare), поэтому список обновляется **снимком из
вашего браузера**:
- `turbo-proxy/apps-script.gs` — хранилище в Google Apps Script (уже развёрнуто, ссылка `/exec` прописана в блоке).
- `turbo-proxy/install-bookmark.html` — откройте и перетащите кнопку «⟳ Обновить сайт IM» на панель закладок.
- Открыли страницу салона на turbo.az → нажали закладку → «✓ Сайт обновлён: N машин».

Делайте это, когда добавили или сняли объявление. Новые посетители видят изменения сразу, повторные — в течение 10 минут.
Секретный ключ записан в `apps-script.gs` и в закладке, он должен совпадать. Не пересылайте его посторонним.

## Фирменный шрифт IM Sans

«IM» и названия моделей (IM LS9, L7…) набраны шрифтом IM Sans (Regular + Bold). Он встроен прямо в
`00-globals.html` и загружать его в Tilda не нужно. В шрифт оставлены только латиница, цифры и знаки (~14 КБ на
начертание вместо 8 МБ); обрезанные файлы лежат в `fonts/`. Для обычного текста шрифт не подходит:
в нём нет азербайджанских ə, ğ, ı, ş и кириллицы.

## Как править тексты

Каждая фраза записана трижды:
```html
<span data-l="az">Test sürüşü</span><span data-l="ru">Тест-драйв</span><span data-l="en">Test drive</span>
```
Меняйте текст внутри нужного `data-l`. Видим только активный язык.

## Фото

Сейчас картинки грузятся с `portal-static.immotors.com`. Параметр `x-oss-process=image/crop…` обрезает
низ кадра, где на исходниках есть китайские подписи. Для продакшена лучше скачать фото и загрузить
в Tilda (Настройки → Файлы), затем заменить ссылки: так быстрее загрузка из Азербайджана и
нет зависимости от чужого CDN.

- **Стили и скрипты страниц** — `blocks/00-pages.html` (вместе с `00-globals` в `<head>` или в общей шапке).
- **Данные моделей** — `pages/data/models.json`: тексты на трёх языках, цифры, фото, цвета, характеристики. Источник — таблицы конфигураций immotors.com (LS6 EREV — данные производителя 2025 г.).
- **Сборка**: `bash build.sh` → `perl build-pages.pl` создаёт блоки `pages/<модель>/m*.html` и страницы `<страница>.html` для просмотра. Правьте данные в JSON, а не блоки моделей — блоки перезаписываются.
- **Фото IM** обрезаются через `?x-oss-process` (по умолчанию верхние 70% кадра — ниже у IM китайские подписи). Список фото с размерами — `pages/data/imx-images.tsv`, цвета — `imx-colors.tsv`.
- **Превью по ссылке**: `bash build-preview.sh` (`preview.pl` переписывает ссылки `/ls9` → `ls9.html`, `/#imxStock` → `home.html#imxStock`).
- **Калькуляторы** (`/calcm`, `/calcd`, `/economy`) в новый дизайн не переносились: нужны актуальные цены. Ссылки на них из подвала убраны.
- **Старые адреса** `/ls6erev`, `/ls9erev` перенаправляются (301) на `/ls6`, `/ls9` — правила в `_redirects`, их пишет build-cf.pl.
